พจนานุกรมฉบับซาราซาคสกุล + Zaan Translate (ZRF.AI)

ติดตั้ง
1) Deploy โฟลเดอร์นี้บน Vercel ตามเดิม (ไม่ต้องใส่ API key ใด ๆ ไม่เรียก AI ภายนอก)
2) Supabase → SQL Editor → รัน supabase-zrf.sql

ZRF.AI ทำงานอย่างไร
- ความรู้เริ่มต้น: คำและนิยามจากพจนานุกรมใน Supabase + กฎไวยากรณ์จากหนังสือ (SVO, ไม่ผันคำ, ชื่อคงเดิม, การเชื่อมเสียงไม่เปลี่ยนการสะกด)
- ทุกการแปลถูกบันทึกลงตาราง zrf_history
- ผู้ดูแล (ตั้งค่าระบบ → ZRF.AI): ยืนยัน/แก้คำแปล, สอนคู่ประโยค, แล้วกด "ฝึกโมเดล ZRF.AI"
- ฝึก: เก็บความจำคำแปล + เรียนรู้บริบทที่ใช้เลือกความหมายของคำซ้ำ (Naive Bayes) แยกชุดทดสอบ 20% เพื่อวัดความแม่นยำ
- โมเดลเก็บในตาราง zrf_model ทุกเครื่องโหลดไปใช้ได้ทันที ยิ่งข้อมูลที่ยืนยันมาก ยิ่งแม่น

ความฉลาดในตัว ZRF.AI (v2)
- อ่านรูปแบบความหมายในพจนานุกรมได้ 3 แบบ: "ใช้… หมายถึง X", "X คำอธิบาย", "X" และคำในวงเล็บ/หลังเครื่องหมาย /
- แยกชนิดคำเป็น N, V, PRON, AUX, CLF ฯลฯ แล้วใช้ไวยากรณ์ SVO เลือกคำซ้ำ (เช่น Pä เป็นคำช่วย "จะ" หรือกริยา "วิ่ง")
- จัดลำดับตามระดับภาษา: คำหลักในพจนานุกรม → คำทั่วไป → คำสุภาพ/ทางการ → ราชาศัพท์
- ยิ่งมีคู่ประโยคที่ยืนยันแล้ว ยิ่งเรียนรู้ลำดับชนิดคำและบริบทของคำซ้ำได้แม่นขึ้น

โมเดลที่ฝึกไว้แล้ว (ZRF corpus v1)
- zrf-model.json  = โมเดลที่ฝึกแล้ว เว็บโหลดใช้ทันทีถ้ายังไม่มีโมเดลใน Supabase (ไม่ต้องทำอะไรเพิ่ม)
- zrf-corpus.json = คลังประโยคฝึก 7,388 ประโยคที่สร้างจากพจนานุกรม + หลักไวยากรณ์ (ประโยค-กริยา-กรรม, ไม่ ก่อนกริยา, จะ/กำลัง ก่อนกริยา, คำบอกเวลาต้นหรือท้ายประโยค, คำคุณศัพท์ตามหลังนาม, คำถามวางคำถามในตำแหน่งของสิ่งที่ถาม)
- เมื่อผู้ดูแลกด "ฝึกโมเดล ZRF.AI" ระบบจะรวมคลังนี้กับประวัติที่ยืนยันแล้วทุกครั้ง
