พจนานุกรมฉบับซาราซาคสกุล + Zaan Translate (PWA)

โลโก้และไอคอนของเว็บ/PWA ใช้ไฟล์จริงในโฟลเดอร์ /icons (สร้างจากโลโก้ที่ผู้พัฒนาให้มา) ไม่ต้องพึ่งเว็บภายนอก
  icons/app-logo.jpg, icon-192.png, icon-512.png, icon-maskable.png, apple-touch-icon.png

ขั้นตอนเปิดใช้ Zaan Translate
1) Deploy โฟลเดอร์นี้บน Vercel ตามเดิม (มีโฟลเดอร์ api/ ด้วย ต้องอัปโหลดทั้งหมด)
2) Vercel → Project → Settings → Environment Variables
     GEMINI_API_KEY = (API key จาก Google AI Studio)      ← จำเป็น
     GEMINI_MODELS  = gemini-3.8-flash,gemini-3.6-flash,gemini-3.5-flash-lite   ← ไม่ใส่ก็ได้
   ค่าเริ่มต้นใช้ Gemini 3.8 Flash ก่อน และสำรองรุ่นอื่นเมื่อรุ่นแรกใช้งานไม่ได้
   แล้วกด Redeploy
3) Supabase → SQL Editor → รันไฟล์ supabase-translate.sql (สร้างแคชกลาง + ตารางบริบทคำซ้ำ)
4) เข้าหน้าผู้ดูแล → ตั้งค่าระบบ → กด "วิเคราะห์บริบทคำซ้ำด้วย AI" (ทำครั้งเดียว/เมื่อเพิ่มคำซ้ำใหม่)

ทำไมเก็บคีย์ไว้ที่ Vercel: ถ้าใส่ในโค้ดหน้าเว็บ ใครก็เปิดดูแล้วเอาโควตาฟรีไปใช้จนหมดได้

แนวทางแปลและการควบคุมเครดิต
- ประโยค/วลีหลายคำส่งให้ Gemini อ่านประโยคเต็มและบริบทก่อนเลือกคำจากพจนานุกรม ไม่แปลเรียงคำแบบตรงตัวโดยอัตโนมัติ
- ใช้ thinking level สูงสำหรับการแปล; ระบบอาจใช้เวลามากกว่าเดิมเพื่อให้ตรวจความหมายละเอียดขึ้น
- คำศัพท์เดี่ยวที่ตรงกับพจนานุกรมคำเดียวใช้ผลในเครื่องเพื่อลดการใช้เครดิต
- เก็บผลในแคชเครื่องและแคชกลาง (Supabase) และใช้ namespace แคชใหม่เพื่อไม่ดึงผลเก่าที่อาจแปลผิด
- ส่งตัวเลือกพจนานุกรมแบบมีโครงสร้าง พร้อมประเภทคำ ความหมาย และบริบท ไม่ส่งเพียงรายการคำแบบย่อ
- จำกัดการเรียกต่อเครื่อง/วันและต่อ IP/นาที; หาก AI ใช้ไม่ได้จะแจ้งชัดเจนว่าผลที่แสดงเป็นเพียงผลจากพจนานุกรมและอาจคลาดเคลื่อน
- ผู้ดูแลปิด AI ได้ที่ ตั้งค่าระบบ → "เปิดใช้ AI ใน Zaan Translate"

หมายเหตุ: คุณภาพยังขึ้นอยู่กับความถูกต้องและความครอบคลุมของคำศัพท์/ไวยากรณ์ในพจนานุกรมด้วย หากไม่มีคำที่ตรงกับความหมาย ระบบจะไม่สามารถสร้างคำซานที่ยืนยันได้เอง


ความปลอดภัยของคีย์ API
- ห้ามใส่ GEMINI_API_KEY ใน index.html หรือ commit ลง GitHub
- หากคีย์เคยถูกส่งในแชต/ภาพ/โค้ด ให้เพิกถอนคีย์นั้นและสร้างคีย์ใหม่ แล้วเก็บคีย์ใหม่ใน Vercel → Settings → Environment Variables เท่านั้น
